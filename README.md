# Сортировщик 3D-моделей (Model Download Sorter)

**English:** a Chrome / Yandex Browser extension (Manifest V3). Downloaded `.stl`, `.step`, `.stp` and `.3mf` files, and `.zip` archives from known model sites, go to `<Downloads>/3D Models/<site>/<model>/`: MakerWorld, Printables, Thingiverse or Other. Point the [PlatePilot](https://github.com/GNUGiminot/platepilot-orcaslicer) plugin for OrcaSlicer at `3D Models`, and each model shows up as a source of its own. To install, download the release zip, unpack it, open `chrome://extensions`, turn on Developer mode and choose Load unpacked. The interface is in English and Russian. Nothing is sent anywhere. MIT licence.

Расширение для Chrome и Яндекс Браузера (Manifest V3). Скачанные модели `.stl`, `.step`, `.stp`, `.3mf` и архивы `.zip` с сайтов моделей браузер сам кладёт в отдельную папку, разложенную по сайтам:

```
<папка загрузок браузера>/
  3D Models/
    MakerWorld/original-3d-benchy/Original_3DBenchy.3mf
    Printables/cable-clip/clip.stl
    Thingiverse/spool-holder/thing.zip
    Other/spiral-vase/vase.stl            ← Cults3D и все остальные сайты
```

Зачем: плагин [PlatePilot](https://github.com/GNUGiminot/platepilot-orcaslicer) для OrcaSlicer может следить только за `…\Downloads\3D Models`, а не за всей папкой загрузок со сторонними архивами. В PlatePilot подпапка с файлами показывается одним источником, поэтому по умолчанию каждая модель кладётся в свою подпапку (выключается в настройках).

## Установка (распакованное расширение, режим разработчика)

1. Скачайте `model-download-sorter-<версия>.zip` со страницы [Releases](https://github.com/GNUGiminot/model-download-sorter/releases) и распакуйте его в постоянную папку, например в «Документы».
2. Установите эту папку в браузер, как описано ниже.

Расширение ставится **папкой**, а не файлом. Полностью автоматически это сделать нельзя: Chrome не даёт сторонним программам ставить расширения не из магазина.

**Быстрый путь:** запустите `install.cmd` двойным щелчком. Он откроет страницу расширений в Chrome или Яндекс Браузере (если есть оба — спросит) и скопирует путь к папке в буфер обмена. Останется включить «Режим разработчика», нажать «Загрузить распакованное расширение», в окне выбора вставить путь в адресную строку (Ctrl+V, Enter) и нажать «Выбор папки». Можно сразу указать браузер: `install.cmd chrome` или `install.cmd yandex`.

Вручную:

**Chrome**
1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика» (переключатель справа вверху).
3. «Загрузить распакованное расширение» → выберите распакованную папку `model-download-sorter` (ту, где лежит `manifest.json`).

**Яндекс Браузер**
1. Откройте `browser://extensions` (или «Настройки» → «Дополнения» → внизу «Расширения для разработчиков»).
2. Включите «Режим разработчика».
3. «Загрузить распакованное расширение» → та же папка.

Папку после установки не перемещайте и не удаляйте: браузер берёт расширение прямо из неё. После изменения файлов нажмите «Обновить» (круглая стрелка) на карточке расширения.

### Настройки браузера, без которых не заработает

- **Папка загрузок.** Путь расширение может задать только внутри папки загрузок браузера. Если там `D:\Downloads`, модели окажутся в `D:\Downloads\3D Models\…`. В PlatePilot укажите именно `…\3D Models`.
- **«Всегда спрашивать, куда сохранять файлы»** — если включено, браузер покажет окно «Сохранить как» с уже подставленной папкой; удобнее выключить.
- **Конфликт расширений.** Если ещё одно расширение переименовывает загрузки (`onDeterminingFilename`, например другие «сортировщики загрузок»), браузер применит только одно из них. Отключите второе.

## Как определяется сайт

По порядку: адрес страницы, с которой начата загрузка (`referrer`), адрес файла (`url`), адрес после перенаправлений (`finalUrl`), а если этого не хватило (например, загрузка через `blob:`) — адрес вкладки, откуда скачали, или активной вкладки. Совпадение по домену и его поддоменам: `makerworld.com` и `bblmw.com` (CDN MakerWorld), `printables.com`, `thingiverse.com`.

- `.zip` переносится только с сайтов из списка — архивы с других сайтов остаются где были.
- Остальные типы с неизвестных сайтов идут в `Other`.
- Подпапка модели называется коротко и латиницей (до 40 знаков, слова через дефис). Имя берётся из адреса страницы модели (`makerworld.com/ru/models/1123776-original-3d-benchy` → `original-3d-benchy`), иначе из заголовка страницы до первого « — » или « | » с транслитерацией (`Держатель для катушки — …` → `derzhatel-dlya-katushki`), иначе из имени файла. Имя самого файла не меняется.
- Одинаковые имена браузер не перезаписывает, а добавляет « (1)».

## Настройки

Кнопка расширения на панели или «Параметры расширения» открывают страницу настроек:

- включить/выключить раскладку;
- общая папка (по умолчанию `3D Models`, можно пусто или `3D Models/Модели`);
- список «папка → адреса сайта», добавить и удалить сайт (например, `Cults` → `cults3d.com`);
- папка для остальных сайтов (`Other`);
- типы файлов: `.stl`, `.step`, `.stp`, `.3mf`, `.zip`;
- «Каждую модель — в свою подпапку».

Язык интерфейса — по языку браузера: русский или английский.

## Проверка

**Юнит-тесты** функции выбора папки (Node 18+):

```bash
npm test
```

**Ручная проверка** (после установки):
1. Откройте любую модель на makerworld.com, скачайте 3MF или STL.
2. В «Загрузках» браузера (`Ctrl+J`) → «Показать в папке»: файл должен лежать в `3D Models\MakerWorld\<имя-модели>\`, например `original-3d-benchy`.
3. То же на printables.com: `3D Models\Printables\<имя-модели>\`.
4. Скачайте с любого сайта файл не-модели (PDF, картинку) — он должен остаться прямо в папке загрузок.
5. В настройках выключите «Каждую модель — в свою подпапку», скачайте ещё раз — файл ляжет прямо в `3D Models\MakerWorld\`.

Что уже проверено: 14 юнит-тестов; автоматический прогон в Chrome 157 с временным профилем и подставными сайтами (загрузки с `makerworld.com` и с сайта Cults легли в свои подпапки, ZIP с Cults остался в корне; прогон был до перехода на короткие латинские имена). На настоящих MakerWorld/Printables и в Яндекс Браузере ещё не проверялось.

## Файлы

| Файл | Что это |
|---|---|
| `manifest.json` | описание расширения (MV3), разрешения `downloads`, `storage`, `tabs` |
| `background.js` | обработчик `chrome.downloads.onDeterminingFilename` |
| `rules.js` | выбор папки — чистые функции, общие для расширения и тестов |
| `options.html/.css/.js` | страница настроек |
| `_locales/ru`, `_locales/en` | тексты интерфейса |
| `test/rules.test.js` | юнит-тесты на `node:test` |
| `install.cmd` | открывает страницу расширений и копирует путь к папке |

Разрешение `tabs` нужно, чтобы прочитать адрес и заголовок вкладки, с которой скачана модель. Расширение никуда ничего не отправляет. В Chrome Web Store его пока нет.
